## Selected projects

**[SkillDrill](https://github.com/furqann76/SkillDrill)** — Technical interview practice platform with AI-generated and AI-graded questions.
Django + DRF backend, React + TypeScript (Vite) frontend. Questions and scenario grading run on a local LLM (Qwen 2.5 7B via Ollama); embeddings (nomic-embed-text) deduplicate the question bank. Includes progress analytics, a leaderboard, and a pytest suite.

**[Lumi&So](https://github.com/furqann76/Lumi-So-ecommerce)** — Django 5 e-commerce platform.
Cart, wishlist, checkout and order history; Celery tasks (Redis broker) for abandoned-cart recovery emails and competitor price tracking; Ollama-generated product descriptions; a separate FastAPI RAG chatbot over store policies (FAISS + sentence-transformers).

**[rag](https://github.com/furqann76/rag)** — FastAPI microservice for question answering over PDFs.
PyMuPDF chunking, sentence-transformers embeddings, FAISS retrieval, Groq-hosted Llama 3 for answer generation.

**[Nerdy Posts](https://github.com/furqann76/Nerdy-posts)** — Django blog platform with a DRF API.
API-key authentication, request throttling, profiles and comments, plus an embedded FastAPI PDF Q&A service.

**[Portfolio](https://furqann76.github.io/Portfolio/)** — Single-page personal site (HTML/CSS/JS, no framework).
